HTML エイチティエムエル について

HTMLとは
先ほども簡単に触れましたが大本となるWebページの骨組みや
構造を定義する言語です。
文章、見出し、リスト、
画像、リンクなどを指定し、ブラウザや検索エンジンにページの内容を伝える役割を持っています。
web上で機能するための
設計図として大切な役割があるということです。

大まかに分けるとこんな感じです。

私たちの目に見えること

  1. テキスト…文章です。
    今こうして見てもらっていますね。
  2. メディア…画像や動画・音楽です。
    通販サイトとかで商品の紹介や説明に
    よく使われていますね。
  3. リンク…urlをクリックすると関連ページに
    移りますよね？これは画像にも適応できます。
  4. フォーム…入力欄です。
    名前やメールアドレスを入力したりログインを求められた時パスワードを入れますよね？

    あの箱に書き込めるようにしています。

私達に見えない部分

今度はwedページでは表示されないけど、
読み込ませることで有利になる部分の解説です。

  1. キーワード設定…これを設定することでアクセス
    しやすいサイトが作れます。

  2. Googleのサービスとリンクさせる…これはまたCSSで説明しますがPCやスマホでは使用できるテキストフォントが違います。

    なので、サイトのイメージが崩れないようにwed上でフォントを統一する必要があります。
    入れなくても動きますがイメージ一つで意外と印象が変わるので侮れません。
  3. 特定の外部ファイルを読み込む…CSSやJavaScriptはHTMLに書いても動きますが、

    基本的にファイルを分けます。

    そしてJavaScriptは自分で作ることも出来ますが、GoogleサービスのようにJavaScriptを外部サイトから持ってくることも出来ます。
  4. 必要な所にタグやIDを付ける…
    ここは特に大事です。CSSとJavaScriptに
    仕事をしてもらうために名札やニックネームを付けてあげます。
見えない部分がないとどうなるの？

キーワードがないと、
検索しても結果に表示され辛くなります。

検索の優位性が変わるのは結構大事です。

例えば温泉旅行に行くとして、温泉だけで検索するとたくさん候補が出てきます。

九州で観光もしたいな？と考えていたのに他の都道府県の表示が多く、探してる九州の候補が出てこないとします。
ここに、大分や鹿児島と
検索ワードを加えると
大分県や鹿児島県が優先的に検索候補に表示されます。

キーワードを設定していれば、検索上位に表示されるのでアクセスが増える。
というわけです。

もう一つ重要なのは
タグとIDです。
先ほど、名札や
ニックネームを付けると
紹介しました。

テキストや見出しなど、
皆それぞれに決まった名前を持っています。
ですが、名前だけでは
CSSやJavaScriptで
動かしたい時に、
同じ名前同士に影響してしまいます。

同じ名前のAが全部赤色になった。
アニメーションでAだけ
動かしたいのにAがいる
部屋ごと動いてしまった。
といった具合に思ったように指示出来なくなります。
それを避けるために、
君はテキストの田中くん。タイトルの君には動いて
欲しいからアニメさん。

こうやって役割が何なのか分かりやすくしてあげます。
こうすることで、CSSやJavaScriptは名前と名札が一緒のこの人と仕事するんだ！となります。
ここを怠るとCSSやJavaScriptは迷子になり大雑把にページ全体を変えてしまったり思ったように
動かないと言った不具合が起きてしまうのです。

長くなっていましたね💦
少なくてもここでは、

  1. 後々整理するためにニックネームや名札を付けてあげること。
  2. 配置したい物を置けること。
  3. 検索しやすいようにキーワードを考えてあげること。
    4. これだけでも覚えてもらえると嬉しいです。

編集するには？

じゃあ、自分で作りたい
けど色々ソフトとか高価な機能がついたPCがいるん
でしょう？
と 思われると思います。

そんなことはありません。
PCに最初から入っているメモ帳機能を使うことで wedページを作ることが
できます。
確かにコードやHTML要素など細かな部分はありますが、内容を理解していれば
メモ帳に 記述し保存先をhtmlやcssで書き出すことで制作できます。

どうでしたか？

メモ帳でこんなことが
出来るなんて意外だった
でしょう？

と言っても、仕事では
おそらくメモ帳で編集は
していません。

大抵はWordPressワードプレスや
Visual Studio Codeビジュアルスタジオコード を
使っています。

メモ帳はダメなの？

誤解がないように言うと、メモ帳で作るのが悪い。
というわけではありません。

メモ帳で作ってもちゃんと動きます。
安心してください。
先ほど挙げた二つの
はメモ帳には無い違いがあるんです。

WordPressワードプレスは
コードを知らなくても サイトやホームページを作れるソフトです。

ここでは簡単にメリットとデメリットだけ説明します。

    メリット
  1. 知識がなくても簡単にブログやサイトを
    作れる。
  2. レイアウトが準備してあるので選んで使える。
  3. アップロードするためのサーバーがあるので
    すぐにwebへ公開出来る。
    デメリット(あくまで個人の感想です)
  1. お金が掛かる…ソフトは無料ですが
    サーバー代などは有料です。
    安くて月額1000～2000円位
  2. WordPressのサーバーに不具合や更新があると影響が出る
  3. セキュリティーの安全面…Visual Studio Codeと違いこちらは外部の管理アプリなので
    ハッキングの心配がある。
    (これに関してはバックアップと更新さえ
    怠らないなら問題ない)

というのがWordPressです。

Visual Studio Code ビジュアルスタジオコード について

Visual Studio Code ビジュアルスタジオコード
（以降はvscと略します）
と呼ばれるオープンソースのコードエディターが
あります。

ありがたいことに無料で
誰でもダウンロードできます。
Microsoftが開発したツールでWindows、macOS、Linuxといった大抵のOSで
編集可能となっています。

オープンソースについての説明は割愛しますが、ここでは企業だけでなく個人も使える便利なソフトと
考えてください。

ではVSCは何ができるのか？
メモ帳との大きな違いを
考えてみました。

  1. 作業のしやすさ
  2. コードの読み解きやすさ
  3. 扱いやすいこと

この3つを私なりに説明しやすいように分けてみました!!

JavaScriptって？

JavaScriptジャバスクリプトは、 HTMLとCSSと組み合わせることで動きのあるページを作る
プログラミング言語です。
まとめてしまうと動作や仕組みを担当する箇所です。
でも、説明だけでは分からないので動作を見てみましょう。

JavaScriptが得意な事

まずはJavaScriptの動きを見てみましょう。HTMLについてお話したページにもありました。
今回は画像を変更しましたが、同じように動きます。
クリックorタップすると画像が拡大されます。
これはクリックもしくはタップされたら画像を拡大するという動作をJavaScriptで処理をしています。

難しいスクリプトなんて作れないよ！

自分の思うようなスクリプトなんて組めない…
と感じている人もいるでしょう。（私もそうです）
そこで活躍するのが jQuery ジェイクエリー というJavaScriptです。
このjQueryを乱暴に解釈するなら、アシスト機能だと考えてください。
jQueryを追加することで、大抵は作りたいコードを記述するだけで動くようになります。
※jQuery単体でJavaScriptは動きません。

どんな書き方をするの？

では動きを見てみましょう！
今回は計算結果が表示される。というJavaScriptでやってみましょう。
１+１＝２と計算するスクリプトを作ってみます。
まずはスクリプトのタグを置きます。
＜script＞＜/script＞と記述し必要な動作を中に入れていきます。
数値を入れるだけでは計算することはできないので、数値をいれるための箱を用意します。
今回はlet aと let b let cという箱を用意します。
このletという部分は宣言です。これを使用することで数値を代入することができるようになります。
変数や代入等説明すると長くなるので、今回は数値を入れるための箱がいることを覚えてください。
ちなみに、宣言する単語はletではなくても動きます。

では、宣言したaとbに数値をいれます。
a = 1　b = 1と入力します。考え方としては数学の代入と同じです。
次に計算式を記述します
c = a + bと記述します。これでaとbを足した結果がcとなります。
最後に計算結果を表示する記述をいれます。
これが無くても計算自体はできますが、結果を表示するために今回は入れます。
alert(c)と入力します。ではここまでをまとめて記述します。
＜script＞
let a, b, c;
a = 1;
b = 1;
c = a + b;
alert(c);
＜/script＞
では、結果をみてみましょう！

今回は動作をみるだけの記述でしたが本来であれば、目的に応じてスクリプトを作成します。
